01

Three ways people actually use it

A WHOLE FOLDER
python combine_mp4.py ./clips \
  -o output.mp4

Every .mp4 inside, natural-sorted, so clip2 lands before clip10 like a civilised person expects.

EXACTLY THESE, IN ORDER
python combine_mp4.py intro.mp4 \
  body.mp4 outro.mp4 -o final.mp4

Name the files and they go in the order you named them. Add --no-sort if you want that guaranteed.

A GLOB, BECAUSE OF COURSE
python combine_mp4.py \
  "footage/*.mp4" -o reel.mp4

Quote the pattern so your shell hands it over intact. Duplicates get dropped, order preserved.

REFERENCE

Every flag, no mystery

There are four of them. You will probably only ever use two.

usage: combine_mp4.py [-h] [-o OUTPUT] [--no-sort] [--reencode] inputs [inputs ...]
FLAG
WHAT IT DOES
inputs
One or more MP4 files, glob patterns, or a directory. A directory pulls in every .mp4 and .MP4 inside it. Required — at least one.
-o, --output
Where the result lands. Defaults to combined.mp4 in the current directory. Missing folders get created for you.
--no-sort
Keeps your exact argument order instead of natural-sorting by filename. Use it when the filenames lie about the order.
--reencode
Skips the fast stream-copy attempt entirely and re-encodes straight away. Worth it when you already know the clips don't match and don't want to watch the first attempt fail.
-h, --help
Prints usage plus the examples from the docstring.

What happens under the hood

PASS 1 · STREAM COPY

The concat demuxer with -c copy. Nothing is decoded, nothing is degraded, and it finishes about as fast as your disk can move bytes.

Only works when every clip shares codec, resolution and frame rate.

PASS 2 · RE-ENCODE

If pass 1 fails, the concat filter takes over and normalises everything to H.264 crf 18 + AAC 192k, with +faststart so it streams properly.

Slower, but it basically always works.

Edge cases it already handles

→ Passing one file just copies it to the output and exits cleanly.
→ The same file listed twice is de-duplicated by absolute path.
→ A pattern that matches nothing warns on stderr instead of dying silently.
→ Filenames with apostrophes are escaped in the concat list.
→ Exit code is 1 if both passes fail, so it behaves in a shell script.
